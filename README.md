# 키즈스키 (ski-for-kids) ⛷️

가족 단위 스키어를 위한 **어린이 스키 가이드** 모바일 웹 앱(PWA).
기술 중심의 인터스키/레이싱 콘텐츠에서 벗어나, 아이와 함께 **안전하고 즐겁게**
레저 스키를 즐기는 데 필요한 것들을 쉽게 알려줍니다.

## 주요 기능

- **오늘의 스키 지수** — 기온·체감·강수·신설·바람·시야·설질을 종합해 0~100점과
  5단계 등급(최고/좋음/보통/주의/나쁨)으로 "오늘 스키 타기 좋은 날인지" 판정.
  슬러시/파우더/아이스 등 설질 추정 포함. 국내 주요 스키장 11곳 + 일본 인기
  스키장 5곳 내장, [Open-Meteo](https://open-meteo.com) 무료 날씨 API 사용(키 불필요).
- **오늘의 팁** — 날씨·설질 조건에 맞춰 매일 바뀌는 맞춤 조언.
- **장비 가이드** — 어린이 스키 길이/폴 길이/딘(DIN) 참고값 계산기,
  플렉스·부츠·헬멧·고글·장갑 고르기, 자가 정비 입문, 중고 스키 체크리스트.
- **안전 가이드** — 리프트 안전, FIS 슬로프 규칙 10가지 쉬운 버전,
  준비운동·휴식, 추위·자외선·시야 대처, 미아·부상 시 행동 요령.
- **배움터** — 전체 팁 모음 + 유튜브·해외 가족 스키 커뮤니티 자료 큐레이션
  (한국어 요약 포함).

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

React 18 + TypeScript + Vite + vite-plugin-pwa. 백엔드 없는 순수 정적 SPA라서
GitHub Pages, Netlify, Vercel 등 아무 정적 호스팅에나 `dist/`를 올리면 됩니다.
홈 화면에 추가하면 앱처럼 동작합니다(PWA).

## 참고

- 딘(DIN) 계산기는 ISO 11088 간이표 기준 **참고용**입니다. 실제 바인딩 조정은
  반드시 전문 장비샵에서 받으세요.
- 설질은 기상 데이터 기반 추정치로, 스키장 정설 작업·인공설 상태에 따라
  실제와 다를 수 있습니다.
